# 0012 · 데이터는 저장소에 넣지 않고 받는 스크립트 + 해시 목록으로 · 기대 결과 계산 스크립트는 저장소에

- 날짜 · 상태: 2026-10-21 · 받아들임 · 정함: Claude(설계 02 · 밖에 공개하는 일은 사용자가 따로)

## 맥락

밖에 보여 주려면 다른 사람이 같은 원천으로 같은 숫자를 내 봐야 해요. 병원 A는 Synthea 합성 FHIR 38개(128MB), 병원 B는 MIMIC-IV 데모 2.2(ODbL · PhysioNet 공개)예요. 기대 결과를 센 스크립트는 지금까지 저장소 밖 작업 폴더에 있었어요.

## 결정

1. 데이터 파일은 저장소에 넣지 않아요. `scripts/get_sources.sh`가 공식 주소에서 받고(병원 A는 고정 씨앗으로 다시 만듦), `expected/sources/*.sha256`(원천 43파일)과 대조해요.
2. 기대 결과 계산 스크립트 셋을 `answer_key/`에 넣어, 누구나 `expected/` 여섯 파일을 따로 다시 셀 수 있게 해요(10/21 다시 세어 바이트까지 같음 확인).

## 이유와 대안

- 대안: 데이터를 저장소에 넣기 — 128MB + 32MB · MIMIC 데모는 ODbL이라 다시 배포할 때 조건을 같이 지켜야 함 · Git LFS가 필요.
- 대안: 기대 결과만 두고 스크립트는 감추기 — 「따로 셌다」를 밖에서 확인할 수 없음.
- 같은 씨앗 · 같은 jar · 같은 JDK로 다시 돌린 결과가 같은 파일이었어요(FHIR-LINE-01 · 10/14 repeat 실행).
